# 图片分类器（Web 版）

一个**完全离线、本地运行**的图片整理工具：用 EVA02 模型在本地给图片打中文标签，点选共同标签即可把图移动到对应文件夹；支持标签多选筛选、差分图（同姿势变体）归组整理、GIF 预览与拖动、批量管理。

- 打标引擎：EVA02-Large（ONNX + DirectML，GPU 加速，失败自动回退 CPU）
- 界面：浏览器网页（FastAPI 后端 + 原生前端），无安装、无注册表
- 数据全在本地：不联网、图片不上传

---

## 运行

- 双击 `run.bat`
- 启动后**自动打开浏览器** `http://127.0.0.1:8000`
- 关闭黑窗即退出
- 不需要自动开网页时：设环境变量 `IMG_TAGGER_NO_OPEN=1`

依赖安装（一次性）：`python -m pip install -r requirements.txt`；模型放 `..\eva02\model.onnx` 与 `selected_tags.csv`。

---

## 数据与缓存（跟随程序所在目录，可整包带走）

| 位置 | 内容 |
| --- | --- |
| `<程序目录>\tagdata\` | 打标结果（每个扫描目录一个文件），**标签数据都在这** |
| `<程序目录>\settings.json` | 记住上次目录等设置 |
| 被打包成 EXE 后 | 以上自动改为 **EXE 同目录** 生成 |

打标数据与图库分离：换文件夹、重装、换机器都不丢标签（重新扫描即恢复）。

---

## 主要功能

- **扫描**：可勾选"包含子文件夹"递归；启动自动回到上次目录
- **打标**：只补未打的（可选"重打全部"）；阈值可调；完成系统通知
- **标签**：点标签 = 多选 AND 过滤；搜索/右键改名/合并/删除；预览图内手动加/删标签
- **整理**：移动到文件夹（可撤销最近一次）；文件名搜索；未标/失败快捷统计
- **差分图**：dHash 归组"同姿势变体"，右侧 📁 分组视图 + 菜单"本地建夹并移动整组"
- **预览**：滚轮缩放 + 拖拽平移、上一张/下一张（遵守当前筛选）、GIF 播放（进度条可拖、画面实时跟帧）、右键复制/另存/打开所在文件夹
- **界面**：深色 SaaS 皮肤、缩略图密度 小/中/大、动图缩略图暂停开关、回到顶部

---

## 注意事项

- 移动是**真实移动文件**；若文件已被其它程序占用会跳过并计数。
- 请只启动一个实例（重复启动会提示端口占用，但会自动打开已运行实例的页面）。
- 标签以**绝对路径**记录：整个图库目录换位置后需重新打标。

## 打包分发

可用 PyInstaller（one-dir）把程序+模型打成绿色文件夹发给他人；`tagdata/` 会自动建立在 EXE 同目录，整包可移动。
